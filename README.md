# PowerPeek

A lightweight macOS menu bar utility that gives you a clearer,
more prominent view of your Mac's battery percentage and charging status.

## Download

### Direct download

Download the latest version of PowerPeek from the
[Releases](https://github.com/blueview13/powerpeek/releases) page.

### Homebrew

If you use Homebrew:

```bash
brew install --cask blueview13/powerpeek/powerpeek

The initial implementation refreshes periodically and when the Mac wakes. The menu bar item displays both the icon and percentage by default. The app bundle includes a PowerPeek icon suitable for the DMG and Applications folder.
